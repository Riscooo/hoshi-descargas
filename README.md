# Hoshi: descargas

Aquí solo están las versiones publicadas de **Hoshi**, la app de logros para juegos de Nintendo 3DS: cada versión trae
`hoshi.cia` y `version.json`.

- **La primera vez**: instala `hoshi.cia` de la última versión con FBI.
- **Después**: Hoshi se actualiza sola al abrirla (mira `version.json` de la última versión, baja la `.cia`, comprueba su
  SHA-256 y se instala).
